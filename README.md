## Telco Project

This project is a SQL-based telecom data analysis case study.

### Structure
- SOLUTIONS.sql → SQL queries and explanations
- TABLE_CREATION_SCRIPTS.sql → database schema
- query_results/ → query output CSV files
- data/ → source CSV files

### Tools Used
- Oracle Database
- DBeaver
- Docker
